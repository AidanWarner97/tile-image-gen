Hi all,

Just to give you all plenty notice, there will be an update coming out soon with a decent amount of changes coming.

The changes coming that I’ve got sorted so far:

- Complete rewrite into PHP
    - The current Python system is great, but requires a lot more system resources.
    - Switching to PHP will allow me to bring the hosting resources down.
- Design language update
    - This is to match in with my personal design language which uses a lot of the Catppuccin colours.
    - You can view current implementations on my [main site](https://awarner.co.uk) and my site for [documentation](https://docs.awarner.co.uk).
- Image preview before download
    - When clicking on the generate button, instead of an immediate download, it will show a popup with the generated image so you can dial in the grout more towards the desired look prior to downloading.  This will save a lot on filling up your Downloads folders!

Changes in production:

- Tighter integration with the updates page.
    - Currently this updates page is a separate WordPress site purely for updates.  Forgoing that and bringing it into the main system will help with continuity.
    - Also means it will be faster etc and easier to maintain without the unneeded systems in the way.
- Improved feedback page to be more transparent and easier to submit or support another submission.
- Add support for known tile ranges to be available without having to upload images.

 

If there’s anything you would like adding, please do let me know and I can look into it.
