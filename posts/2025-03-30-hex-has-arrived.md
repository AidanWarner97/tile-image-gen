Finally proud to announce that Hexagon’s are now supported, and the layout has been enabled for use. I’ll admit it’s not perfect, but it’s very close to and should be more than usable in any design software.

Honestly, for a patterned tile, 4 images doesn’t really cut it as the same pattern repeats fairly often, but it’s something I’ll add support for later on. It’ll probably be a case of requiring ~8 images to enable full randomised support without major repetition.

Worth bearing in mind, that the images for the tiles must be length ways. So the points must be width ways. I’ve added an image to show what I mean.

![Hexagon Outline](images/hex-outline.png)

As always, thank you everyone for the continued use. I look forward to adding extra features in the future! And remember, please do use the feedback form for any ideas or issues you run into.

Aidan.
